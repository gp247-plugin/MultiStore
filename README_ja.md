# S-Cart Multi-Store — 1 つの管理画面で複数の EC サイト

> 🚀 **Link MultiStore PRO:** [https://gp247.net/en/product/multi-store-pro.html](https://gp247.net/en/product/multi-store-pro.html)

## はじめに
Multi-Store は、事業者が **1 つの管理システムから複数の EC サイトを運営できる** ようにするプラグインです。本ドキュメントは、事業者のオーナーおよび運用担当者（技術的な知識は不要）向けです。読み終えると、Multi-Store の用途、もたらす価値、Multi-Vendor との違い、そしてニーズに合わせて選べるよう Free 版と Pro 版の違いが分かります。

## 1. Multi-Store とは何か、何を解決するのか
事業者が **複数の異なるストア／ウェブサイト** を持ちたいとき — たとえばブランドごとに 1 つのドメイン、市場ごとに 1 つの言語／通貨、あるいは卸売サイトと小売サイトを分けたい場合 — 一般的な方法は、別々のウェブサイトを複数構築することです。その結果、データが分散し、複数の場所にログインする必要があり、維持コストがかかり、全体を把握しにくくなります。

Multi-Store はすべてを **1 か所** にまとめます：

- **複数のストア、1 つの管理画面。** 各ストアは独自のドメイン、独自のデザイン（テンプレート）、独自の言語と通貨を持ちますが、管理は 1 つの管理画面だけで行えます。
- **共通の基盤。** 商品、注文、顧客は 1 つのシステムにまとまっており、ウェブサイトごとに一から構築し直す必要はありません。
- **コストと手間の削減。** 1 回のインストール、1 か所での運用、1 か所での更新 — 個別のウェブサイトを複数維持する必要はありません。
- **段階的に拡張。** 1 つのストアから始めて、必要なときに新しいストアを追加でき、システムを作り直す必要はありません。

> 👉 デモサイトで実際にお試しください：**https://demo.s-cart.org**

## 2. Multi-Store と Multi-Vendor の違い
これらは **異なる** 2 つのビジネスモデルであり、同じウェブサイトに **一緒にインストールすることはできません**（データの競合を防ぐため、システムがブロックします）。正しいモデルを選んでください：

| 項目 | 🏢 **Multi-Store** | 🛒 **Multi-Vendor** |
|---|---|---|
| 商品の所有者 | **1 人のオーナー**（あなたの事業） | 一緒に販売する **独立した複数の仕入先・出店者** |
| モデル | 同一オーナーによるチェーン店／複数ブランド | EC マーケットプレイス |
| 商品を管理する人 | あなた（システムのオーナー） | 各出店者が自分で出品 |
| 第三者への手数料／支払い | なし | あり — 手数料の分配、出店者への支払いの照合 |
| 向いているケース | **同じ事業** のために複数のウェブサイト／ドメインがほしい場合 | **他の人を招いて** 販売してもらい、手数料を得たい場合 |

簡単に言えば、**Multi-Store = あなた自身の複数のストア、Multi-Vendor = 多くの出店者のための市場** です。マーケットプレイスのモデルが必要な場合は、Multi-Store ではなく Multi-Vendor プラグインをご覧ください。

## 3. Free 版と Pro 版の比較
Multi-Store には **Free 版**（無料、始めるには十分）と **Pro 版**（大規模運用のためにすべての機能を開放）があります。

| 機能 | 🆓 **Free** | ⭐ **Pro** |
|---|:---:|:---:|
| ストア数 | 最大 **3**（ルートストアを含む） | **無制限** |
| 複数ドメイン、ストアごとに独自のデザイン | ✅ | ✅ |
| ストアごとの言語と通貨 | ✅ | ✅ |
| ストアごとの個別設定 | ✅ | ✅ |
| 厳格なドメイン検証（STRICT） | ✅ | ✅ |
| **ストアごとの専任管理者**（そのストアのドメインでログイン） | — | ✅ |
| **ストアへの商品同期**（ルートの商品を複数のストアに掲載し、元商品へのリンクを保持） | — | ✅ |
| **統合ダッシュボード**（ストア間で売上／注文数／平均注文単価を比較、Excel 出力） | — | ✅ |
| システム全体の **商品別売上レポート**（各ストアの複製分を含む） | — | ✅ |
| **ストアのロック／ロック解除**（プラットフォームのオーナーが特定のストアの営業を一時停止） | — | ✅ |

- **Free 版を選ぶとき：** 始めたばかりで、ストアは最大 3 つあれば足り、すべてを自分 1 人で管理する場合。
- **Pro 版にアップグレードするとき：** 3 つを超えるストアが必要な場合、各ストアを専任の管理者に任せたい場合、またはシステム全体の集計レポートが必要な場合。

## 4. ストアへの商品追加と管理権限の付与
複数のストアを運営するときによくある 2 つの運用フローです — 始めるには Free 版で十分で、高度な部分は Pro 版に属します：

- **特定のストア向けに商品を登録（Free 版で利用可）：** Multi-Store をインストールすると、ルート管理画面で商品を作成／編集するときに、商品が属する **ストアを選択** します — 商品はそのストアにだけ表示されます。
- **ルートの商品を複数のストアに掲載（Pro）：** 1 か所（*「ストアへの商品同期」* 画面）から、1 つのルート商品を複数のストアに掲載します。各ストアには元商品へのリンクを保持した独立したコピーが作られ、再同期もできます。
- **ストアごとに専任の管理権限を付与（Pro）：** 各ストアを専任の管理者に任せます（*Store Admin* / *Store Member* の 2 つのサンプルロールを用意）。管理者はストアのドメインでログインし、割り当てられた範囲だけを閲覧でき、ルート管理画面には入れません — **どのような権限が付与されていても、システムレベルの操作は常にブロックされます**。

🔗 上記 2 つの Pro フロー：[gp247.net/en/product/multi-store-pro.html](https://gp247.net/en/product/multi-store-pro.html)

## コマンドラインでのインストール（CLI、gp247 3.x）
gp247 3.x 以降では、管理画面を開かずに、GP247 ライブラリから **MultiStore** をダウンロードしてコマンドラインですぐにインストールできます。ウェブサイトのルートフォルダでターミナルを開き、次を実行してください：

```bash
# 1) ウェブサイトごとに 1 回だけ：GP247 ライブラリに接続するための API License（無料）を登録
php artisan gp247:ext-register-license

# 2) ライブラリからプラグインをダウンロードしてインストール
php artisan gp247:ext-install --type=plugin --key=MultiStore
```

- 手順 1 の前に、`.env` の `APP_URL` がウェブサイトの **実際のドメイン** になっていることを確認してください（`http://localhost` のままにしないでください）。ライセンスはこのドメインに紐付けられます。
- インストールが完了すると、プラグインは **有効化済み** になり、キャッシュも自動で更新されるため、管理画面で追加の操作は必要ありません。
- コマンドは `gp247.json` に宣言された条件（core 3.0、`gp247/shop`、依存プラグイン、Multi-Vendor と同時にインストールしないルール）を自動でチェックします。不足があればコマンドは停止し、何が足りないかを明示します。
- プラグインのフォルダがすでに `app/GP247/Plugins/` にある場合（手動でコピーした、または zip ファイルから展開した場合）、コマンドは再ダウンロードせずに **その場でインストール** します。
- プラグインがすでにインストール済みの場合、コマンドは拒否します。新しいバージョンに更新するには `php artisan gp247:ext-update --type=plugin --key=MultiStore` を実行してください。
- コマンドの末尾に `--json` を付けると、機械可読な形式で結果を受け取れます（スクリプト／CI 用）。
- 詳細：[拡張機能のインストールガイド](https://gp247.net/en/docs/user-guide-extension/guide-to-installing-the-extension.html)。

## 条件と制約（ご利用の前にご確認ください）
- **Multi-Vendor と一緒にインストールできません** — Multi-Store とマルチベンダーは異なるモデルで、ストアのデータを互いに競合する方法で共有します。ウェブサイトにマルチベンダーのプラグインがある場合、システムは **インストールをブロック** します。先にそのプラグインを削除してからインストールしてください。
- **Free 版はストア 3 つまで**（ルートストアを含む） — 始めるには十分です。さらに追加するには Pro 版へのアップグレードが必要です。これは 2 つのエディションの境界であり、不具合ではありません。
- **ルートストア（ROOT）はロックできません** — ルートストアはシステム全体の基盤であり、ロックするとすべてが停止してしまうため、この操作は常にブロックされます（ロック機能は Pro 版に属します）。
- **プラットフォーム要件：** `gp247/shop` が必要で、GP247 core 3.0 以降で動作します。これは S-Cart/GP247 のプラグインであり、単体では使用できません。

## Q&A（よくある質問）
**質問 1：ストアごとに別々のウェブサイトを構築する必要がありますか？**

→ いいえ。インストールするのは 1 つのシステムだけです。各ストアは同じシステムを指すドメインであり、1 つの管理画面でまとめて管理されます。

**質問 2：各ストアに独自のデザイン、言語、通貨を設定できますか？**

→ はい。共通の基盤を使いながらも、各ストアでテンプレート、言語、通貨、その他の個別設定を行えます。

**質問 3：Multi-Store と Multi-Vendor のどちらを選ぶべきですか？**

→ すべてのストアがあなたのものなら Multi-Store を選んでください。さまざまな出店者にマーケットプレイスで販売してもらい、手数料を得たいなら Multi-Vendor を選んでください。

**質問 4：Free 版ではストアをいくつ使えますか？**

→ ルートストアを含めて最大 3 つです。それ以上必要な場合は Pro 版（無制限）にアップグレードしてください。

**質問 5：Pro 版で追加される最も価値のある機能は何ですか？**

→ ストアごとの専任管理者、複数のストアへの商品同期、統合ダッシュボード、システム全体の売上レポート、ストアのロックです — 本格的に複数のストアを運営するための機能です。

**質問 6：現在 Free 版を使っていて、後で Pro 版にアップグレードするとデータは失われますか？**

→ いいえ。Pro 版は同じ基盤上での Free 版の拡張です。アップグレードすると機能が追加で開放され、既存のストアのデータはそのまま保持されます。

**質問 7：決める前に試してみたい場合はどこで見られますか？**

→ 公開デモサイト：https://demo.s-cart.org

**質問 8：なぜマルチベンダーのプラグインと一緒にインストールできないのですか？**

→ 2 つのモデルはストアのデータを異なる方法で共有しており、同時に動かすとデータが壊れます。システムはあなたを守るために自動でブロックします。ニーズに合ったモデルを 1 つだけ選んでください。

**質問 9：インストールと設定の詳細はどこで見られますか？**

→ gp247.net の [インストールのドキュメント](https://gp247.net/en/docs/plugin-multi-store/multi-store-setup.html) と [運用のドキュメント](https://gp247.net/en/docs/plugin-multi-store/multi-store-operations.html) をご覧ください（上記の **ドキュメント** の項目に 4 つのページがすべて記載されています）。Pro 版の購入に関する情報は [製品ページ](https://gp247.net/en/product/multi-store-pro.html) にあります。
